Operating Fact

Not a guess about the world.
A record of what can be established.

Every observation carries its source, observation time, validity, and revision. Consumers can refresh a fact, compare it against a known boundary, and distinguish current evidence from stale or unavailable information.

01 / Observe

One readable current.

Host and desktop sources are brought together as JSON facts. Each value remains attached to the provider that observed it, with unavailable sources represented honestly rather than filled in by inference.

02 / Understand

Spatial facts, with boundaries.

Explore monitor layout, workspaces, focus, and window geometry. Verified compositor frames stay distinct from accessibility extents and estimates.

03 / Compare

Revision-aware evidence.

Fences and receipts let independent consumers reason about what changed after a known revision, without confusing observation with proof of an action's effect.

A deliberate boundary

WORLDLINE observes.
It does not act.

No input injection. No window activation. No action policy. WORLDLINE provides a trustworthy observation surface; the systems that consume it retain responsibility for decisions and actuation.

Independent by design

Shared reality.
Separate responsibilities.

GWCU uses WORLDLINE as an independently managed source of operating facts. GWCU owns execution policy and causal completion verification; Cua Driver remains the actuator. Both consumers can reason against the same WORLDLINE revision domain without WORLDLINE taking control of the desktop.

Get started

Give your tools a better view.

WORLDLINE targets Ubuntu with GNOME on Wayland. Install the managed user service from a terminal in your desktop session.

sudo apt install git python3 python3-venv python3-pyatspi libglib2.0-bin zip
git clone https://github.com/ryanraposo/WORLDLINE.git
cd WORLDLINE
./scripts/worldline-install.sh install
./scripts/worldline-install.sh status

The installer asks before enabling the read-only GNOME Shell frame extension. Review the permission before approving it. WORLDLINE does not send input or activate windows.
